          Ablage

            Noten & Wunschnote

            So funktioniert's
            1. Trage in Karte 1 jede Note ein, die du schon hast (Schularbeit, Test, Mitarbeit …).
            2. Gib an, wie stark sie zählt (Gewicht). Zählen alle gleich viel, lass überall 1 stehen.
            3. In Karte 2 siehst du, welche Note du bei der nächsten Prüfung höchstens schreiben darfst, um dein Ziel zu erreichen.

            Skala: 1 = sehr gut … 5 = nicht genügend. Je kleiner der Schnitt, desto besser.

            1 · Note eintragen

            Gewicht = wie stark die Note zählt, z. B. Schularbeit 2, Test 1, Mitarbeit 0,5.

            2 · Wunschnote berechnen

            Ein Ziel gilt als erreicht, wenn der Schnitt höchstens bis zur halben Note danach reicht (Ziel 2 = Schnitt bis 2,5). Nur ein Richtwert – die Note legt die Lehrkraft fest.

            3 · Schularbeiten-Rechner

            Für Englisch mit Listening, Reading, Language in Use und Writing, aber auch für jedes andere Fach mit Teilbereichen. Jeder Bereich hat ein Gewicht in Prozent und eine eigene Höchstpunktzahl. Wähle eine Vorlage oder stelle alles selbst ein. Die Voreinstellungen folgen den Beurteilungskriterien österreichischer Gymnasien (Oberstufe: vier Bereiche zu je 25 %, positiv ab 60 %, beide Gruppen Rezeptiv und Produktiv mindestens 50 %). Unterstufe: Bestehen ab 50 %. Gewichte, Punkte und Grenzen legt aber jede Lehrkraft selbst fest, vergleiche sie deshalb mit deinem Angabenblatt.

            Fächer / Module

              Kategorien (für To-Dos)

                Konto und Sync

                Angemeldet als

                Mit deinem Konto bleiben To-Dos, Tests, Noten, Zusammenfassungen und Einstellungen auf allen Geräten gleich. Änderungen von mehreren Geräten werden pro Eintrag zusammengeführt. Hochgeladene Dateien bleiben auf dem jeweiligen Gerät. Supplierplan und Kalender-Links gelten pro Gerät.

                Einrichtung (einmalig, für den Betreiber)
                1. Auf supabase.com ein kostenloses Projekt anlegen.
                2. Im Projekt unter „SQL Editor“ das folgende SQL ausführen.
                3. Unter „Project Settings“ die Project URL und den öffentlichen Schlüssel (anon oder publishable key) kopieren und unten eintragen. Den geheimen service_role Schlüssel niemals eintragen.
                4. Unter „Authentication“ und „URL Configuration“ die Adresse eintragen, unter der der Hub liegt (Site URL). Ohne sie führen die Links in den Mails ins Leere. Wer keine Bestätigungsmail will, schaltet unter „Sign In / Providers“ bei E-Mail „Confirm email“ aus.
                create table if not exists public.hub_data (
  user_id uuid primary key default auth.uid() references auth.users(id) on delete cascade,
  data jsonb not null,
  updated_at timestamptz not null default now()
);
alter table public.hub_data enable row level security;
create policy "hub_select" on public.hub_data for select to authenticated using (auth.uid() = user_id);
create policy "hub_insert" on public.hub_data for insert to authenticated with check (auth.uid() = user_id);
create policy "hub_update" on public.hub_data for update to authenticated using (auth.uid() = user_id) with check (auth.uid() = user_id);
create policy "hub_delete" on public.hub_data for delete to authenticated using (auth.uid() = user_id);

                Der öffentliche Schlüssel darf sichtbar sein. Die Daten schützen die Regeln aus dem SQL: Jeder sieht nur die eigene Zeile. Mails verschickt das kostenlose Supabase nur in kleiner Zahl. Für größere Gruppen lässt sich unter „Authentication“ ein eigener Mailserver (SMTP) eintragen.

                Alternative: Sync-Code (ohne Konto)

                Der Code ersetzt Anmeldung und Passwort. Er läuft über den Cloudflare-Worker aus den Einstellungen oben. Ersten Code auf Gerät 1 erzeugen, dann auf allen anderen Geräten denselben Code eintragen. Der Code ist dein Passwort, bitte gut aufbewahren. Mit einem Konto auf diesem Gerät ist der Code nicht nutzbar.
